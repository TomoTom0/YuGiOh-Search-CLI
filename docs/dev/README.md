# 開発向けドキュメント

このディレクトリには、開発・保守作業に関する記録とドキュメントが置かれています。

## ディレクトリ構成

### records/
開発履歴、マージ競合解決記録など、過去の開発作業の記録を保存しています。

**例:**
- `2025-11-19_merge-conflict-resolution.md` - マージ競合の解決記録

## 用途

このディレクトリは主に以下の目的で使用されます：

- 複雑なマージ競合の解決プロセスの記録
- 重要な開発決定の履歴
- トラブルシューティングの記録
- アーキテクチャ検討の記録
