# v1.4.0 (2026-01-18)

## New Features

### CLIコマンド統合とライブラリ化

- 8つの個別CLIコマンドを`ygo_search`のサブコマンドとして統合（`card`, `faq`, `extract`, `replace`, `seek`, `update`）
- CLIスクリプトの関数をライブラリとしてexport可能にした（`extractCardPatterns`, `extractAndSearchCards`, `judgeAndReplace`, `seekCards`, フォーマット変換機能等）

### Vector DB機能

- TSVからVector DBを構築する機能を実装（LanceDB + multilingual-e5-small、13,809カード + 12,583 FAQ）
- Vector DB検索機能を実装（cosine/l2/dot距離メトリック、閾値フィルタリング、メタデータフィルタ対応）
- `YGO_SEARCH_WORKDIR`環境変数のサポートを追加（ワークディレクトリのカスタマイズ）
- 汎用データインポート機能（`vector setup-generic`コマンドでyaml/jsonl/json/tsv/csv形式に対応）

### Webフロントエンド

- Vue.js + Viteベースのフロントエンドプロジェクトを構築（`web/`ディレクトリ）
- CLIとWebアプリで共有する環境非依存の共通ロジックを抽出（`src/lib/shared/normalizer.ts`）
- ブラウザ専用CardDatabaseクラスを実装（IndexedDBキャッシュ、fetch API、バックグラウンドプリロード対応）
- FAQ検索用のFaqDatabaseクラスを実装（検索モードパーサー、IndexedDBキャッシュ対応）

### カード検索機能

- 検索モードパーサーの実装（マイナス検索、フレーズ検索、正規表現検索対応）
- 複数フィールド対応（name, ruby, text, pendulumText, supplementInfo, pendulumSupplementInfo）
- 選択肢条件フィルタを実装（カードタイプ、種族、属性、魔法タイプ、罠タイプ、モンスタータイプ、リンクマーカー）
- 数値範囲フィルタを実装（攻撃力、守備力、レベル/ランク/リンク、Pスケール）
- フィールド選択にプリセットを追加（すべて、カード名+ルビ、効果テキスト+Pテキスト、補足情報+P補足情報）
- 数値条件に完全一致チェックボックスと攻撃力・守備力の?検索を追加
- 詳細条件セクションを折りたたみ可能に
- 選択肢条件にトグル式「すべて選択/すべて解除」ボタンを追加
- 選択肢フィルタにAND/OR選択と肯定/否定選択を実装（左クリックで肯定選択、右クリックで否定選択）
- 検索結果の情報量を増加（一覧表示 + クリックで全詳細情報を展開可能に）
- リンクマーカーを3x3グリッドの図形UIで表示・選択可能に

### FAQ検索機能

- FAQ検索UIコンポーネントを実装（FaqSearchForm、FaqList、タブ切り替え）
- 登場カード検索機能とフィールドプリセット選択を追加

### 国際化

- 属性・種族・カードタイプなどの日本語翻訳機能を実装（`web/src/lib/translations.ts`）

### Cloudflare Workers向けRust実装

- 既存TypeScript実装を完全にRustで再実装（48テスト全合格）
- D1データベース統合（カード検索・FAQ検索のクエリヘルパー）
- REST APIエンドポイント5種類（正規化、パターン抽出、パターン置換、カード検索、FAQ検索）
- TSVからD1へのデータインポートスクリプト（import-cards.ts、import-faqs.ts）

## Bug Fixes

- リンクマーカーフィルタのデータ形式（文字列連結形式）に対応し、テンキー配置（1:左下〜9:右上）の8方向が正しく表示・フィルタリングされるように修正
- 検索クエリが空白でも条件フィルタのみで検索できるように修正（カード検索・FAQ検索）
- ネガティブ検索（-キーワード）が全フィールドを横断してチェックされていなかった問題を修正（例：「-アルバス 烙印」で「烙印融合」が正しく除外される）
- テキストフィールドの改行コードが正しく表示されるように修正（`white-space: pre-wrap`を追加）
- 不要なフィールド（ciid, nameModified, isExtraDeck, biko, isNotLegalForOfficial）を非表示に

## Changes
